# 企画書：まいにちナビ2028（就活ストレスシミュレーター）

## コンセプト
大手就活ナビサイトの「マイページ」を本物っぽく模擬し、就活生が受けるストレスを約5分で体験させるネタ系Webサイト。
どれだけ頑張っても最後は **お祈りメール** で終わり、リザルト画面（ストレス指数・称号）をSNSでシェアできる。

- 名称：**まいにちナビ2028**（架空サービス。実在サービスの名称・ロゴ・配色は使わない）
- トーン：本物っぽさ重視。ところどころに「明らかなネタ」の誇張を混ぜる
- 構成：ハイブリッド型（マイページのダッシュボード＋「やることリスト」で次のステージへ誘導）
- 想定プレイ時間：約5分
- 対象企業：東都インテグレート株式会社（架空）

## 画面フロー
```
会員登録 → マイページ(ダッシュボード)
  ├ 1. エントリー（企業ページ / 大量のコース）
  ├ 2. 会社説明会（動画）
  ├ 3. エントリーシート
  ├ 4. Webテスト
  ├ 5. 面接予約
  └ 6. 一次面接
→ 選考結果待ち → お祈りメール（全社から一斉に） → リザルト（シェア）
```

## ステージ別ストレス要素（★＝明らかな誇張ネタ）
| ステージ | 本物っぽいストレス | 誇張ネタ |
|---|---|---|
| 会員登録 | エラーが1件ずつしか出ない／全角スペース・全角カナ・半角数字指定／確認用メールは貼り付け不可／パスワード条件が後出し／メルマガ等が全部チェック済み | ★本登録URLを「クリックしたことにする」ボタン |
| エントリー | コース・インターンが大量／ほぼ全て受付終了・インターン参加者限定／プレエントリー→企業独自マイページへ再登録 | ★「未来共創フロンティアコース（内容は入社後に決定）」★生年月日の年が1940年から始まる |
| 説明会動画 | スキップ・倍速不可／タブを離れると一時停止／確認テスト／99%で送信エラー | ★「何より大切なのは」が3回出る確認テスト（不正解で10分巻き戻し）★「福利厚生の説明が17分続きます」 |
| ES | 3問・文字数制限／改行は2文字扱い／機種依存文字NG／「御社」NG／セッション切れで全消去 | ★一時保存すると設問3だけ消える ★例文が全員同じ |
| Webテスト | 1問10秒／性格検査240問 | ★問題文の読み込みで制限時間の半分が消える ★「回答の一貫性が低い」ため追加質問 |
| 面接予約 | 枠がリアルタイムで埋まる／押した枠が「他の方が予約しました」／キャンセル待ち | ★キャンセル待ちの順番が登録するたびに後ろへ下がる ★追加枠は朝7:30 |
| 一次面接 | 待機室で待たされる／回線不安定 | ★「あなたを動物に例えると？」 |
| 結果待ち | 「1週間以内に連絡」が来ない | ★スカウトメールだけ届き続ける |
| お祈り | 定型文のお祈りメール | ★エントリーしていない企業からも一斉にお祈り |

## 共通ギミック
- ヘッダーに **ストレスゲージ**・仮想日付（2027年3月1日〜）・経過時間
- 未読メッセージが増え続ける（999+）。中身は全員に同じ文面のスカウト
- 定期的に「本日締切！」などの通知トースト
- フッター：推奨環境 Internet Explorer 11 ★

## リザルト
プレイ時間／ストレス指数／エラー回数／入力文字数／お祈り数／称号／ストレスの内訳上位 → X（旧Twitter）でシェア

## 技術構成
- Vite + React + TypeScript（SPA、ルーターは使わず画面状態で切り替え）
- 状態管理：React Context + useReducer
- 公開：GitHub Pages（GitHub Actionsで自動デプロイ）

1. 企画書（本書） 2. 環境構築 3. 共通レイアウト 4. 各ステージ実装 5. お祈り・リザルト 6. 動作確認 7. 公開
